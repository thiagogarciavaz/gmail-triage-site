gmail-triage — Privacy Policy

Last updated: November 11, 2026

gmail-triage is a personal, single-user command-line tool that helps its owner organize their own Gmail account (labeling, archiving and trashing unwanted senders). It is not offered to the public and has no other users.

What the app accesses

With the owner's explicit consent, the app uses these Gmail permissions:

  • gmail.modify: read message metadata and change labels, archive, or move messages to Trash. The app never permanently deletes messages.
  • gmail.settings.basic: create Gmail filters for senders the owner has chosen to block.

How data is handled

  • Message metadata (sender address, subject, date, unsubscribe headers) is stored in a local database on the owner's own computer.
  • Nothing is uploaded to servers operated by the app's developer. The app has no backend.
  • Data is not sold, shared for advertising, or used to train generalized AI models.
  • When AI-assisted classification is enabled, limited data (sender address, truncated subject and Gmail snippet; in rare cases a truncated message body) may be sent to the Anthropic API solely to decide whether a message is unwanted. Messages from senders the owner has marked as protected are never sent. Message bodies are never written to logs.
  • Access tokens are stored in a local file readable only by the owner.

Google API Services User Data Policy

The use and transfer of information received from Google APIs to any other app will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revocation

The owner can delete the local database and token file at any time, and can revoke the app's access at myaccount.google.com/permissions.

Política de Privacidade (resumo em português)

O gmail-triage é uma ferramenta pessoal, de um único usuário, para organizar a própria caixa do Gmail do seu dono. Não é oferecida ao público.

  • Acessa os metadados dos e-mails (remetente, assunto, data, cabeçalhos de cancelamento) e altera rótulos, arquivo e lixeira. Nunca apaga definitivamente.
  • Os dados ficam em um banco local no computador do dono. Não há servidor do desenvolvedor.
  • Nada é vendido, usado para publicidade ou para treinar modelos de IA.
  • Com a classificação por IA ativada, dados limitados (remetente, assunto truncado e trecho do Gmail) podem ser enviados à API da Anthropic só para decidir se o e-mail é indesejado. Remetentes protegidos nunca são enviados.
  • O acesso pode ser revogado em myaccount.google.com/permissions.
